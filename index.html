Code example: manual heap allocation in C

A deliberately small illustration of the kind of low-level work I practise: a bump allocator over a fixed buffer, with no standard library allocation.

#include <stddef.h>
#include <stdint.h>

static uint8_t heap[4096];
static size_t  used = 0;

/* Returns an 8-byte-aligned block, or NULL if the heap is exhausted. */
void *bump_alloc(size_t size) {
    size_t aligned = (size + 7u) & ~(size_t)7u;
    if (aligned < size || aligned > sizeof heap - used)
        return NULL;
    void *p = &heap[used];
    used += aligned;
    return p;
}

Illustrative snippet written for this portfolio; my full allocator work is not yet public. More code is in the DSAProj repository.
